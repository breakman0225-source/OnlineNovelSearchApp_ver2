# なろう小説拡張検索サイトver2 要件定義書.md

## 1. プロジェクト概要

### 1.1. 背景
ver1の時点で、「OR検索を実装したバージョンの検索サイトを制作する」という目的は達成したが、なろう運営との面談やピッチコンテストの出場などの経験を踏まえて、今の状態では制作物として就活でアピールするには弱く、またユーザーから見た使い勝手も悪いと感じたため、新機能の実装が必要だと判断した。

### 1.2. 現状の課題
- 気になる小説を一時保存する機能がない。
- API通信の最適化がされていない。
- そもそもデプロイされていない。

### 1.3. 目的（ゴール）
- なろうAPIのgzip機能を活用した通信量の削減と、ローカルストック機能を用いたページネーションの共通化によるAPI通信の最適化。
- 気になる小説を一時保存するローカルDB機能の実装。
- 開発したアプリケーションを外部公開するためのデプロイ。

### 1.4. 非目標（スコープ外）
※開発の肥大化を防ぎ、限られたリソースで本バージョンを確実に完成させるため、以下の項目はver2のスコープ外とする。
- R18小説の同時検索機能の実装
- ローカルLLMの組み込み
- AND/OR検索のUI改善（初見ユーザー向けのわかりやすさ向上）
- お問い合わせ機能の実装

---

## 2. システム要件

### 2.1. 機能要件
- **小説の一時保存（ローカルDB）**
  - 検索結果から特定の小説データをローカルDBに保存できる。
  - 保存した小説の一覧を閲覧できる。
  - 保存した小説をローカルDBから削除できる。

### 2.2. 非機能要件
- **パフォーマンス（API通信の最適化）**
  - なろうAPIの通信時にgzip圧縮を利用し、レスポンスのデータ量を削減する。
- **保守性**
  - AND検索のページネーション処理を、OR検索で使用しているローカルストック機能を用いた方式に統一する。

### 2.3. インフラ・運用要件
- **デプロイ**
